# 数字果蝇：表示框架与实测状态

这份文档记录两件事，它们在本项目里是同一件事的两面：

1. **表示框架**——「一个神经元是什么对象」「整个网络用什么矩阵描述」。
   这不是抽象讨论：本文第四节到第七节的每一条实测失败或成功，都能追到框架里缺的某一项。
2. **实测状态**——当前信号能传到哪、传不过去的机制是什么、已排除哪些解释。

框架部分是设计对话的产物，实测部分是可复现的数字（`--` 开头的都是本程序的选项）。

## 一、表示：神经元是什么对象

**坏形式：神经元 = 标量。**
当前实现把每条突触压成一个数（由**突触计数**与**突触前递质符号**导出），
每个神经元只有一个状态 `v`。实测后果见第七节。

**中间形式：神经元 = n×m 矩阵**（入度 n，出度 m，`B[e][e'] = 入边 e' 对出边 e 的贡献度`）。

但对**点神经元**它是冗余的：神经元只有**一个**输出信号 `y`，被复制到 m 条边上——

```
s_j = q_j · f( Σ_i w_i x_i )        ⇒  线性化后 s = q · wᵀ · x
```

**外积，秩 1**，可因式分解成 n+m 个数 ⇒ 相对边表冗余约 n 倍。
带时间也救不了秩：频域上 `M_ji(ω) = Q_j(ω)·W_i(ω)`，**每个频率上仍是秩 1**。

**让 n×m 不可约的，只有两件事**：

| 机制 | 说明 |
|---|---|
| **区室化（树突子单元）** | 不同输入落在不同分支、分支内各有非线性 ⇒ 映射不可分离 |
| **多个独立输出位点** | 脉冲输出与分级输出取自**不同的输入池** ⇒ 秩可 >1 |

**秩的上界**：同一个神经元、同一类输出边 ⇒ 那些列**完全相同**（`f_i` 与 `L` 都相同）
⇒ 类内秩 1 ⇒ `rank(B_v) ≤ 输出类别数`。
要让秩升上去只有两条路：**增加输出类别**，或**让不同类别读不同的输入子集**（= 输入侧拆子单元）。

**注意**：同一个 `w` 送进 m 个不同下游神经元，各自与不同输入混合 ⇒
**差异化由下游制造**，不需要在输出侧制造。但类别之间必须在 `f_i`、`q_e`、输入划分
三者之一上不同，否则类别结构只是装饰。

## 二、边空间：l×l 矩阵，它是分块对角的

把表示逆转：以**边**为下标（l = 突触数）。则「边 e' 传到神经元里之后对边 e 的贡献」
非零的条件是 `post(e') = pre(e)`——e' 进入的神经元正好是 e 离开的那个。

于是按 `pre(e)` 分组行、`post(e')` 分组列：

```
                 e' →  （按 e' 进入的神经元分组）
            ┌────┬────┬────┬────┐
       e↓   │ B₁ │    │    │    │   B_v = m_v × n_v
   （按 e  │    ├────┼────┤    │   = 第 v 个神经元的
   离开的   │    │ B₂ │    │    │     「入边 → 出边」算子
   神经元   ├────┼────┼────┤    │
   分组）   │    │    │ B₃ │    │   空白处是结构性为零
            ├────┼────┼────┼────┤
            │    │    │    │ ⋱  │
            └────┴────┴────┴────┘
```

**这是连接组的「有向线图」（directed line graph）的加权邻接矩阵。**

**它不是稠密的，是分块对角**：h 块，第 v 块 m_v×n_v。

| 对象 | 元素数 | float32 |
|---|---|---|
| 稠密 h×h（解剖，神经元空间） | 166700² = 2.78×10¹⁰ | 111 GB |
| 每个神经元的算子 Σ nᵥmᵥ | 166700 × 153.46² ≈ 3.93×10⁹ | 15.7 GB |
| **实际非零（解剖）** | **25,582,938** | 102 MB |
| 稠密 l×l（边空间） | 25582938² = 6.54×10¹⁴ | **2.62 PB** |
| 边空间实际非零（= Σ nᵥmᵥ） | 3.93×10⁹ | 15.7 GB |

稀疏度：神经元空间 **0.092%**；边空间分块对角 **6×10⁻⁶**。

**这个表述的价值在于它把计算因式分解了**：

```
s_{t+1} = Q · Φ( A_incᵀ · s_t )
          └┘   └┘  └────┘
          广播  算子  聚合
         (l×h)      (h×l)
```

**聚合与广播都只是簿记（稀疏关联矩阵），唯一有真正参数的是 Φ。**
改 A、改索引、改稀疏格式都不可能让网络"会算"新的东西——只能改 Φ。

### 那个矩阵是「状态」，不是「参数」

`w = f(L)` 是每条边**当场算出来的值**，不是固定权重。它的变化分三层：

| 层 | 什么变 | 时间尺度 | 实现代价 |
|---|---|---|---|
| ① 输入变 | `L` 变 ⇒ `w` 变 | 每步 | **零**（现算现用） |
| ② 局部增益变 | `f` 形式不变，但在当前工作点的**导数**变（阈值、分流、去阻遏） | 每步（由状态定） | **零**（f 里已含） |
| ③ **函数本身变** | `f` 的参数变（短时程可塑性、调质） | 10 ms ~ 分钟 | **每条边一个状态变量 = 102 MB** |

**只有第③层需要额外存储。** 不变的是结构（哪条边存在）与 `f` 的函数形式。

### 稀疏算子 → 稠密响应

解剖矩阵 A 稀疏，但**有效连接** `J = (I−M)⁻¹ = I + M + M² + …` **一般稠密**
（稀疏矩阵的逆稠密；M² 已连上两跳的神经元对）。同样的故事在边空间重演：
B 分块对角，但 B²、B³… 的和会填满。

**所以"非稀疏 h×h"的说法对应的是 J（有效连接），不是 A（解剖连接）。**
我们从不显式构造 J（O(h³) ≈ 10¹⁵ 不可行），仿真只每步做一次稀疏乘（25.6M MAC/步），
让递归隐式地实现它。这也解释了为什么"加增益"这种局部改动会有非局部后果。

## 三、Φ 的 13 个自由度

"对网络的把控全部落在 f_i 上"是准确的，但**"增强/抑制"只覆盖第 1 项**——
而那正是上文证明过的退化特例。连"抑制"本身都有两种，数学上不同：

```
减性抑制：I → I − g_inh            （移平衡点）
除性抑制：I → I·g_exc/(g_exc+g_inh) （分流，按比例压缩）
```

实测（`cellsim` 台架）：固定兴奋驱动，抑制电导 1.0 / 3.0 / 10 时输出保留
**96% / 88% / 64%** ——**乘性压低，不是减一个常数**。

| # | 自由度 | 买到什么 | 当前 |
|---|---|---|---|
| 1 | 符号 + 增益 | 增强 / 抑制 | ✅ |
| 2 | 阈值 + 整流 | 死区、稀疏化 | ✅（含阈值异质性） |
| 3 | 复位 / 不应期 | 饱和、率编码 | ✅ |
| 4 | 膜时间常数 | 低通、时间整合 | ✅（基本全局 100 ms） |
| 5 | 通道类型与时间常数（逐边） | 延迟线、快慢分离 | ⚠️ 框架有（5 通道），默认只用快通道 |
| 6 | 电压依赖（乘法） | **巧合检测**、门控 | ⚠️ 只有 CH_NMDA，且只给 T4/T5 |
| 7 | 分流（除法） | **归一化** | ✅（电导形式 + `--norm-gain`） |
| 8 | 分级 vs 脉冲 | 模拟量传递、绕过阈值 | ✅（按类型分配，`--bio-graded`） |
| 9 | **短时程可塑性** | 记忆、随历史变的权重 | ❌ |
| 10 | 调质 / 状态依赖 | 增益重设、学习 | ❌ |
| 11 | **输入侧子单元** | 质上独立的多路输入 | ❌（所有输入落在一点） |
| 12 | 输出侧多类别 f_i | 时间多样性（快递质 vs 神经肽） | ❌ |
| 13 | 间隙连接 | 无延迟双向耦合 | ❌ |

**经验规律：本项目每一次可测量的成功，都是"自由度从 1 加到 2~3"的那一步**
（电导化 → 除法；电压依赖 → 一个乘法；分级 → 绕过阈值；归一化 → 又一个除法）。

## 四、自激活：两种形态，以及判据

生物脑的静息态**不是静默**：闭眼时 α 节律最强，默认模式网络就是专门命名这种
"自发生成的、有结构的"状态的。感觉输入只占总突触驱动的一小部分——
**刺激不是从零创造活动，而是扰动一个正在进行的活动。**

但"自持"本身不是判据。两种截然不同的东西：

| | (a) 吸引子景观 | (b) 单个饱和不动点 |
|---|---|---|
| 状态数 | **多个可区分状态** | **一个** |
| 输入的作用 | **选择**落到哪个状态 | 什么都不改变 |
| 信息 | 有 | **零** |

**判据（可直接测）**：给不同刺激 → 撤掉 → **留下的状态是否不同？**
用 `--stim-off-after` 实现。

**实测（`--graded-amp 4`，各给 2 秒后撤掉）**：

| 刺激 | cb_intrinsic | descending | vnc_motor |
|---|---|---|---|
| **无** | 12.16 | 3.15 | 3.57 |
| 条纹 | 11.82 | 3.43 | 3.56 |
| 逼近 | 12.60 | 3.42 | 3.51 |

⇒ 自激活真实存在（无刺激也有 12.16 Hz），但**三种刺激留下同一状态** —— 目前是 **(b) 退化形态**。

**设计目标因此是**：不是"让它自激活"（它已经会），而是**让自激活支持多个可区分状态、
并由输入选择**。机制上要从"全局饱和"走向"稀疏竞争编码"——
网络里已有 **59,262 个抑制性神经元（35.5%）**，所以缺的不是结构，是**增益区间**
（接近临界 + 侧抑制足够强）。

**"学习 = 生长出环"需要修正**：环**已经在**（cb_intrinsic 85.34% 来自自身递归）。
学习要做的是把这些环的增益调到临界附近（少数模 |λ|≈1，其余 <1）。

## 五、连接组给了什么、缺什么

| | 连接组给的 | 需要的 |
|---|---|---|
| 稀疏模式 | ✅ | ✅ |
| 每条边的**符号** | ✅ 由突触前递质**预测** | 概率性；调质类不能这么定 |
| 每条边的**强度** | 只有**突触计数** | 量子大小 × 释放概率 × 受体类型 |
| 每条边的**核**（时间结构） | ❌ | 快慢通道、短时程可塑性 |
| 输入的**空间结构** | ✅ 可反推方位角 | 区室归属 |
| 输出位点 | 部分（axon/dendrite） | 各输出位点的输入池 |

**所以连接组给的是一个「秩 1、零记忆、只有符号」的草图**——
缺的正好是让 n×m 变成满秩的那几件东西。

**一个已知的具体错误**：符号规则是「GABA/谷氨酸/组胺 → −1，其余 → +1」。
对果蝇**恰好正确**（果蝇谷氨酸主要经 GluCl 抑制），但**多巴胺/章鱼胺/血清素/酪胺/神经肽
全被判成"+1 快速兴奋性突触"**——它们其实是调质。（待查：这些占多少突触。）

## 六、实测状态数字汇总

### 数据规模
- h = **166,700** 神经元；l = **25,582,938** 突触；平均入/出度 153.46
- 抑制性 59,262（35.5%）

| ol_intrinsic（视叶内部，含 T4/T5） | **3233 显著 / 群体 d′ 266.5** | 258 显著（≈假阳性期望 217）/ **0.0** |
| ol_sensory | 444 / 184.8 | 13 / 0.0 |
| 全脑 | 3699 (3σ) / 935 (5σ) | 280 / 2 |
| visual_projection | 0 / 0.0 | 0 / 0.0 |
| cb_intrinsic | 0 / 0.0 | 0 / 0.0 |
| descending_neuron | 0 / 0.0 | 0 / 0.0 |
| vnc_motor | 0 / 0.0 | 0 / 0.0 |

**注意**：修正前（伯努利方差）给出的「2694 显著 / d′ 234.6」不可靠 —— 那个统计量对
占总细胞多数的分级细胞不成立。修正后的数字 **3233 / 266.5** 才是可用的。

逐类型 CV d′（半→半 / 反向），六个 T4/T5 亚型**信号两半都为正、对照为负**：
T5c +23.5/+18.5、T5b +24.3/+21.1、T4a +14.6/+20.5、T4d +12.5/+16.1、T4b +9.7/+11.1、T4c +9.0/+11.4。

### 为什么传不过去（三条实测的机制）

**① 驱动构成被自身递归主导**（`offline_drive_comp.py`，|权重| 占比）：

| 目标群体 | 来自上一级 | 自身递归 |
|---|---|---|
| visual_projection | 68.45%（ol_intrinsic） | 17.90% |
| **cb_intrinsic** | **5.95%** | **85.34%** |
| descending_neuron | 53.16%（cb_intrinsic） | 16.16% |
| **vnc_motor** | **9.35%** | **81.22%** |

**② 逐通路增益只能过一级**：`--path-gain ol_intrinsic visual_projection 5`
让 vp 从 6/0.0 变成 162/70.1（跨过一级**脉冲**突触），再加 5 倍到 cb/descending 完全无效。

**③ 每级只有一部分细胞携带调制，下一级对全部输入取平均** ⇒ 逐级稀释。
`ol→vp` 的 5 倍增益正是把那一部分细胞的权重占比从 ~2% 提到 ~10%。

### 工作点：紧张性 / 位相性必须分开标定

分级链传 `A·(s_k − base·out_rest_k)`（分级细胞静息输出 0.5，绝对值会把网络灌饱和）：

| base | 刺激贡献（注入80 对 注入0） |
|---|---|
| 0.0（绝对电平） | 703535 / 703015 ⇒ **0.07%** |
| 0.35 | 2.5% |
| 0.5 | 4.4% |
| **0.7** | **8.0%** ← 最优 |
| 1.0（纯偏移） | −4.0% |

位相性增益 `--graded-amp`：amp=1 → descending 0.00 Hz；amp=4 → 3.04；amp=10 → 43.64。
**但对照显示 amp=10 时注入 80 得 cb_intrinsic 44.07、注入 0 也得 44.07**——
**"活动到达运动层"是靠自激活，不是靠传信号。**

### 已关闭的路：方向选择性

- 台架（`cellsim` test ⑥）用**实测参数**（每腿 7 条输入、簇宽 5°、慢腿占 14.6%、
  空间周期 0.8 rad、漂移 183°/s、dt=1 ms）给出：**Δc=0 时 DI 恒等于 0.0000**（机制正确），
  但**最优工作点的上界只有 ~3%**，网络实际工作点（输出 0.02）下只有 ~0.005 ⇒ 测不到。
- 离线几何（`offline_hrc_geom.py`）：两条腿的**平均空间偏移只有 0.2~0.3°**，
  而细胞间散布 ~5.5° ⇒ 连接组在这层**没有空间基线**。
- 显式空间基线（`--hrc-shift 8.25`，重接 122,067 条慢腿边，匹配速度
  `8.25°/45ms = 183.3°/s` 与刺激完全一致）后**仍然没有方向选择性**（T4a/T4d 未出现相反偏好）。
- **结论：不是实现 bug，是机制可用幅度不够。已关闭。**

## 七、仪器与方法的错误清单

**每一个都曾让结论反向。列在这里是因为「先怀疑自己的量，再怀疑实验」。**

| # | 错误 | 症状 |
|---|---|---|
| 1 | 聚合 10σ 假阳性 | 把逐神经元的 z 直接求和，噪声堆出大数 |
| 2 | 占空比不平衡的 CV d′ | 80/20 窗口让慢漂移被当成信号（motor d′ 62，幅度改 0 后一模一样） |
| 3 | 周期标签与网络自身振荡锁相 | `--pattern reverse` 的标签按固定周期翻转，与网络的确定性振荡锁相 |
| 4 | **`群体 d′ = sqrt(Σz²)` 的 sqrt(N) 噪声底** | 纯噪声下 E[z²]=1 ⇒ 结果 ≈ √N；ol_intrinsic 有 89275 个细胞 ⇒ 恒给出 ≈300，**与刺激无关** |
| 5 | 分级细胞用伯努利方差做 CV d′ | 假设 `p(1−p)`，对连续输出不成立 ⇒ 符号翻成 −333 |
| 6 | **`out > 0.5` 把分级细胞计成"发放"** | 分级细胞静息输出恰好 0.5 ⇒ 5 万个细胞恒被计为发放 ⇒ 报"总发放 800 万"，据此错误宣布"网络饱和"（真实是脉冲细胞 0.00~1.2 Hz） |
| 7 | **CV d′/显著性检验用伯努利方差** | 假设每步输出 0/1，对**分级细胞**（连续输出）不成立 ⇒ 符号翻成 −333；且让对照"看起来"干净 |
| 8 | **漏掉时间自相关** | 膜时间常数 100 ms = 5 步，把每步当独立样本 ⇒ 有效样本数高估约 √5 倍 ⇒ 标称 3σ 实际 ~1.4σ。症状：只修 #7 之后，注入 0 的对照给出 ol_intrinsic 7570 显著、群体 d′ 437（假阳性期望只有 217） |

**#7 与 #8 必须一起修，只修一个会比原来更糟**：
伯努利方差（原）→ 对照 182 显著（假象）→ 只改经验方差 → 对照 7570 显著、d′ 437（更糟）
→ 再加 AR(1) 修正（有效样本数 n_eff = n(1−ρ)/(1+ρ)）→ 对照 **258** ≈ 假阳性期望 **217** ✓
对应代码：`var_of_mean()`（经验方差 + AR(1)），三处调用（显著性检验、`eval_cv`、`cvtype`）。

**我自己写出来的 bug**（同样是"结论反向"级）：

- 分级注入漏掉 `inj_amp` ⇒ 注入 80 与注入 0 **逐位相同**，幅度 0 对照彻底失效
- 用 PowerShell 正则改写源码，吃掉整个文件的新行（恢复办法：`cmd /c "svn cat -r N f > f"` 是字节级重定向）
- 默认路径写错导致「重接 0 条慢腿边」而**无任何报错**（静默失败比报错危险）
- 变量名大小写冲突（`$A`/`$a`）让一次"关键对照"实际跑成了无意义的组合
- `test/ffbo` 的 ninja depfile 缺失 ⇒ **改头文件不触发重编**，ninja 说"最新"而 exe 是旧的

**方法学结论**：每条结论都必须配一个能推翻它的对照，且**幅度 0 对照必须与实验同参数跑**；
2 秒周期的标签必须配 ≥30 秒的运行（6 秒只有 3 个周期，与慢漂移混叠，
对照的 `平均|Δ|` 被抬到与信号同量级）。

## 九、谱分析：递归矩阵没有放大能力（本节的结论关掉了一整条路线）

用 `offline_spectrum1..4.py`（离线，不跑仿真）。

### 9.1 关键数字

```
SCC 数: 1385      最大强连通分量 165,314 (99.17%)  ← 真正的大脑
#41064 ENS 所在分量: 大小 2（入度 1 出度 1）      ← 孤立 2-环，是伪影
主回路 ρ(A) = 0.91503          ⇒ 临界增益 syn_gain* = 1/ρ = 1.093
```

**踩过的坑**：第一遍在全矩阵上算，得到 `ρ = 1.00000`，我据此宣布"归一化把网络强制定在临界点"。
**错了**——那 λ=1 来自成千上万个 2 细胞孤立自循环（不是主回路）。只在最大强连通分量上重算
才得到真实的 **ρ = 0.915**。

（顺带：`syn_gain` 默认 60 ⇒ ρ(W) = 60×0.915 = **54.9**，即 50 倍超临界。所以"临界点在 1 附近"
这个方向是对的，但"归一化强制 ρ=1"是错的。）

### 9.2 格林函数：稳态增益 ≈ 1.0，没有放大

`offline_spectrum4.py` 解 `s = (γI − A)⁻¹ b`（GMRES；非对称稀疏矩阵直接 LU 分解填充会爆炸）：

| γ | 视觉输入 ‖s‖/‖b‖ | 全脑均匀输入 |
|---|---|---|
| 2.000 | 0.493 | 0.522 |
| **1.000（稳态）** | **0.989** | **1.165** |
| 0.950 | 1.047 | 1.269 |
| 0.920 | 1.088 | 1.349 |
| 0.916（≈ρ） | 1.093 | 1.361 |

**γ 逼近谱半径时完全不发散。** 即：

> **递归矩阵对输入（视觉的或均匀的）都没有放大能力，稳态增益 ≈1。**

推论：
1. 「cb_intrinsic 85% 驱动来自递归」**不是放大现象**，只是突触总量大部分落在递归上。
2. 高 `syn_gain` 下的自激活**不是线性放大**，是把 50 倍超临界的系统推过阈值、由非线性饱和出来的。
3. **逐级 5~10 倍的衰减不可能靠增益补回来**——它只能来自
   **非线性（阈值：只有一部分细胞过阈）** 与 **前馈稀疏性（每级只有一部分输入被调制）**。

### 9.3 联调实测（印证 9.2）

`syn_gain` 同时缩放信号与递归（视觉信号也穿过 W），所以它分不开两者。只削弱各群体**自耦合**
10 倍也失败（信号与递归一起被杀）。联合标定（降 syn_gain 到临界附近 × 提高 `--graded-amp`）：

| syn_gain | amp | ol_intrinsic | visual_projection | cb_intrinsic | descending | vnc_motor |
|---|---|---|---|---|---|---|
| 1 | 80 | 11.1% | 11.5% | 0% | 0% | 0% |
| 2 | 80 | **13.1%** | 5.6% | 0% | 0% | 0% |
| 4 | 80 | 9.6% | 0% | 0.3% | 5.7% | 1.3% |

刺激贡献在浅层从 0.07% 提到 **~13%**（约 180 倍），但到 `cb_intrinsic` 塌回 0.3%。

### 9.4 因此被排除的方向

- ❌ 加通路增益（没有放大可取，只能过一级）
- ❌ 找"输入与慢模对齐"（格林函数显示无共振可对齐）
- ❌ 靠 `syn_gain` 调工作点（它与信号共用同一个矩阵，分不开）

### 9.5 因此剩下的方向

1. **非线性侧**：阈值/分流决定"多少细胞能过阈"。这正是 Φ 的自由度清单里第 2、7 项。
   实测证据：分流归一化 β=0.25 曾让视叶 d′ 从 234.6 → 337.4（+44%，对照干净）。
2. **前馈稀释侧**：提高"每级携带调制的细胞比例"。
3. **补 Φ 缺失的自由度**（清单第 9–13 项），尤其第 9（短时程可塑性）与第 11（输入子单元）。

## 十、工作点联合优化：结论与架构判定

用修正后的统计量（第七节 #7/#8），以「显著数超过假阳性底」为目标，扫了约 20 个工作点
（`syn_gain` × `graded-amp` × `norm-gain`，覆盖 40× × 80× × 5×）。格式为
**信号显著数 / 对照显著数（该层假阳性期望）**。

| syn_gain | amp | norm | ol_intrinsic | visual_projection | cb_intrinsic | descending |
|---|---|---|---|---|---|---|
| 60 | 1 | 0（默认） | 1576/350 (217) | 1/0 | 0/0 | 0/0 |
| **16** | **1** | **0** | **12084/1059 (207)** ★ | 0/0 | 0/0 | 0/0 |
| 16 | 1 | 0.1 | 11472/1037 (201) | 0/0 | 0/0 | 0/0 |
| 16 | 1 | 0.5 | 714/713 (168) | 0/0 | 0/0 | 0/0 |
| **60** | **1** | **0.25** | **4758/155 (205)** | 1/0 | 0/0 | 0/0 |
| 1.5 | 20 | 0 | 6748/743 (210) | 0/0 | 0/0 | 0/0 |
| 60 | 20 | 0 | — | 1639/**1637** (25) | 83/87 | 4/3 |
| 16 | 80 | 0 | — | 1677/**1676** (25) | 100/91 | 3/2 |
| 4 | 80 | 0 | — | 378/**506** (24) | 139/**208** | 3/6 |
| 60 | 20 | 0.25 | — | 2841/**2843** (25) | 177/165 | 4/2 |

### 10.1 两个结论

**① 浅层有一个明确更优点**：`syn_gain ≈ 16, amp = 1, norm = 0`
⇒ ol_intrinsic **12,084 显著**（对照 1,059，假阳性期望 207）= **53 倍于底**，
比默认设定（1576，5.6 倍）强 **7.6 倍**。这是本项目迄今最强的可用视觉信号。
（另一处很干净的是 `syn_gain=60, norm=0.25`：对照 155，**低于**期望 205，信号是它的 23 倍。）

**② 深层传不过去，且原因已排除「工作点没调对」**
凡是 `visual_projection` / `cb_intrinsic` / `descending` 亮起来的地方，
**信号与对照逐位相同**（1639/1637、1077/1077、1677/1676、378/506、2841/2843）。
这在 syn_gain 跨 40 倍、amp 跨 80 倍、norm 跨 5 倍的范围内**无一例外**。

> **「传信号」与「自激活」在这个架构里互斥**：想要深层亮，只能把网络推入自激活，
> 而那样的亮不含刺激信息。

这条与第九节的谱结论一致：递归矩阵**没有放大能力**（稳态增益 ≈1），
所以不存在"某个增益下信号被放大着传下去"的可能。逐级衰减只能靠
**非线性（阈值）**与**前馈稀疏性**解释，而两者都不是调增益能解决的。

### 10.2 架构判定（据世界设定的判据）

世界设定给出的分界线是：**行为必须从系统自身的动力学里长出来**——
伊什库尔是"被专门构造、没有一丝一毫的多余、不会下棋的工具"，澪的区别是自由意志。
操作化之后：

- **读取**网络自身的状态 ⇒ 允许（那是解码）
- **替**网络计算行为 ⇒ 不允许（那就成了工具）

而实测给出的边界很清楚：**解剖链条从光感受器到运动神经元传不过去**
（20 个工作点全部失败），**但感觉编码这一段是稳健的**（12,084 个细胞、53 倍于底）。

⇒ **采用「已验证的视叶状态作为果蝇的视觉，用解码器读取该状态来闭环」的架构。**
连接组负责感觉编码（已验证），任务层负责闭环（与文献 "visual selectivity emerges from
connectome AND task constraints" 一致，也与 fly64 的做法一致）。
这**不违反**世界设定的判据：读出的是网络自己的内在状态，而不是我手写的输入→输出映射。

### 10.3 因此下一步

把已验证的视叶信号接进 `fly_mcns_view`（带身体的那个程序 —— 目标真正所在），
用解码器读取该状态闭环。注意：近期工作全在 `mcns_net`（正确性验证程序），
身体与渲染那条线还没有接过细胞模型后端。


## 十一、渲染卡顿的根因：每绘制 0.196ms（2026-xx 实测，结论已锁死）

### 11.1 现象

窗口一卡一卡、5.5fps。控制台一直"健康"（帧数在涨、位置在动），
但 `帧内拆分: 帧图执行 110ms | 起止帧+呈现 0.3ms` —— 慢的全在帧图里。

### 11.2 排查路径（每一步都先怀疑自己的量具，三次量具坏了）

| 假设 | 做法 | 结果 |
|---|---|---|
| 阴影 pass 太贵 | `--no-light` 去掉光源 | 109.6 → 112.2ms，**无效**。原因：无光源时 `theory_shadow` 走 `gather_directional` 的默认方向光，阴影图照样渲 |
| 阴影图分辨率太大 | `--shadow-size 512/1024/4096` | 全是 110ms，**无效** —— 但量具坏了：`m_shadow.setup()` 只在 `!ready()` 时调用，改 size 是空操作 |
| 主线程被并行池饿死 | 把 worker 的空闲 `yield()` 自旋改成退避 sleep | 帧时间 109.3 vs 109.2，**无效**；但 MuJoCo 60.5→45.2ms，进程 CPU 从 2839%（32 逻辑核顶满）降下来 —— 这条改动照留 |
| 每绘制 12 次 `vkUpdateDescriptorSets` | `--bench-bind 20000` 直接量 | 0.05µs/次 ⇒ 每绘制 0.001ms，**否定**（此量具也可能被 early-return 污染，见 11.4） |

真正的判据来自两个量：**墙钟 vs 本线程 CPU**（`GetThreadTimes`），以及**逐个 pass 计时**。

- `帧图执行 109.9ms，其中本线程 CPU 107.3ms` ⇒ 不是等 GPU，是主线程自己在烧 CPU。
- 逐 pass（`--perf-pass`）：`shadow 54.8 / scene 54.6 / tonemap 0.45 / gizmo_sync 0.01`。
- `--hide-after K`（只显示前 K 个模型）：K=0 时仍有 **76.8ms** 固定开销，K=999 时 109.6ms。

### 11.3 两个独立的开销源

**① 固定项 76.8ms = 相机坐标 gizmo。**
`--hide-after 0` 时可见 drawer 只剩 `coord` 的 4 个，但 `models::drawer` 仍要 39ms/pass。
`--bench-off` 逐步复现 pass 内部：`begin+end_offscreen 0.005ms`、`clear 0`、
`system::traverse 0.05ms`、`AABB 合并 0.15ms`、**`traverse+drawer 39.0ms（198 次绘制/帧）`**。
即：**4 个 drawer 发出了 199 次 draw** —— `ploys::render()` 对每个 topol 各发一次 `rhi.draw()`，
而 `arrow` 是 2 个 11 段 frustum 网格（几十个 topol）。关掉 gizmo：5.5fps → 9.3fps。

**② 每绘制 0.196ms（核心）。**
`rhi.draw()` 用 3 个顶点的小三角形裸测：**0.183ms 墙钟 / 0.156ms CPU**。
两种完全不同的 drawer（`prefab` 果蝇 / `ploys` gizmo）得到同一个单价，说明开销在共用的绘制路径里：

```
rhi_vk.cpp draw():  std::memcpy(p.ubo_data + dynamicOffset, p.ubo_data, UBO_SIZE);
                    UBO_SIZE = 38240（UBO_MAX_BONES=512 撑起来的，见 backend/ubo.h:44）
```

UBO 缓冲是 `HOST_VISIBLE | HOST_COHERENT` 常驻映射（`vkMapMemory`），
**每绘制一次就把整个 38240 字节从这块大概率是 write-combined 的内存里读出来再写回去**。
38240B ≈ 600 条 cache line 的不可缓存读取 ≈ 150µs —— 与实测 0.156ms 的 CPU 完全吻合。
写侧还有 1024 个 slot × 38240B ≈ 39MB 的环形缓冲，逐绘制换槽 ⇒ TLB/缓存不停失效。

### 11.4 已落地的改动（都不动 xhqm 底层）

| 改动 | 效果 | 物理轨迹 |
|---|---|---|
| `--no-gizmo`（`RhiViewport::gizmo(false)`，initialize 前生效，不再创建） | 5.5 → **9.3 fps** | 逐位不变 |
| `--no-shadow`（`dynamic_cast<theory_shadow*>` → `enabled(false)`，公开 API） | 9.3 → **11.2 fps** | 逐位不变 |
| 并行池空闲等待 spin → 退避 sleep（默认） | MuJoCo 45ms；32 核不再顶满 | 逐位不变 |

**`--phys-dt 0.0005` 被否掉**：MuJoCo 45→10ms，但末位置从 `(-0.986, 0.151, 0.555)`
变成 `(-0.000, 0.259, 0.157)` ⇒ 改变了动力学，不是等价加速。按"先保证正确"保留默认 0.0001。

### 11.5 已实施（授权后落地，r548）——结果见 `RENDER_FIX_PLAN.md`

`rhi_vk.cpp` 绘制路径那次 37KB 全量 UBO 复制已改掉，另修 304 硬编码偏移、`ploys` 合批、
`--shadow-size` 空操作。**帧图执行 110ms → 1.6ms，端到端 5.5 → 13.6 fps，
渲染结果与改前逐像素相同（同一步号快照 SHA256 一致），物理轨迹逐位不变。**

关键修正：最初方案写的「只复制脏前缀」是错的（`world` 在 32KB 的 `bones[]` 之后，
前缀仍到 89%）。正确判据是**「曾经被写过」而非「本次改过」**——UBO 是有状态的块，
一次绘制要读到之前设定的字段，而目的地是本次绘制独占的新 slot，所以必须带全"可能被读到的块"。
这样 `bones`+`instances` 共 36KB 在不写骨骼/实例时整段跳过，主着色器只剩约 1.4KB。
V3（重排布局）因此不再需要。

**顺带修好一个坏量具**：`--shadow-size` 原来是空操作（`m_shadow.setup()` 只在 `!ready()` 时调用），
已加 `m_applied` 判据使其真正重建。修好后实测 256²/512²/2048²/4096² 的 shadow pass 都是约 1.0ms
——**阴影 pass 是绘制/顶点受限，不是填充率受限**；同时 fly 场景里阴影图分辨率**看不出视觉差别**
（on/off 有差别，但 512 与 4096 的图像哈希相同），说明该场景没有可见的自阴影。
这两条都是"修好量具后才敢下的结论"。

### 11.6 改底层时踩到的新坑（已升级为 README 第 10 条诊断纪律）

`xhqm/build` 没有 header depfile（`ninja -t deps` 查不到任何 `.h`），改头文件不会重编包含它的 TU。
于是同一 DLL 里两批 obj 对同一个类有不同布局：新 obj 按新布局访问，旧 obj（`fantasy/property.cpp`）
按旧布局构造 ⇒ **构造出的对象里插入点之后的成员全是垃圾**。现场是 `theory_shadow::m_enabled`
恰好读成 0，阴影 pass 静默 early-return，图像"看起来还行"，只有拿 shadow on/off 两张图对哈希
才发现完全一样。判据：改过头文件就必须 `Remove-Item build\CMakeFiles\xhqm.dir -Recurse -Force`
后全量重编（90 个 TU）。

**当场遇到一次实证**：r551 提交后 `svn update` 拉进 r546（给 `fantasy::drawer` 加虚析构）与
r550（给 `geometry::shape` 加虚析构）—— 两个都是改布局的头文件，而当时的 DLL 还是按旧布局编的。
按上述判据全量重编后复核：帧图执行 1.7ms、物理 `(-0.9860 0.1505 0.5552)`、图像 SHA256 仍是
`EFD3CC34…`，三者与重编前一致 ⇒ 并发改动没有改变渲染结果，我的改动也仍然成立。
**推论：本仓库只要有人动了头文件，本机就必须全量重编，不能信 ninja 的 "no work to do"。**


### 11.7 V4：描述符集环改成每 program 独立 + 回卷零等待（r553）

原来 `MAX_DESC_SETS=1024` 的轮转计数是**一个全局计数被所有 program 共用**，消耗速度 = 全场总
绘制数/帧（果蝇 445/帧 ⇒ 每约 2.3 帧转满一圈 ⇒ 一次 `vkDeviceWaitIdle`）。改成每 program 自己
一份计数，并给回卷加了可判定的安全性（上次回卷至今 ≥ 在飞帧数 ⇒ 那一圈必然已完成 ⇒ 零等待）。

实测：交换链只有 2 张图（在飞 2 帧），每次回卷 gap 4~6 ≥ 2 ⇒ 全部走快路径，**一次设备空闲都没有**。

**但 A/B 没测出这个场景的差别**：旧路径稳态也不掉帧（都是 0 个 >20ms 的帧）——
因为每帧 GPU 只落后约 1.6ms，设备空闲很快就返回。所以这是**结构性**收益而非本场景提速：
任何单帧总绘制数 >1024 的场景，旧代码是**每帧**触发设备空闲；新代码按 program 计根本不回卷。
顺带把 `vkDeviceWaitIdle`（设备级、含呈现队列）换成只等自己提交的 fence。

同时给视口加了**掉帧尖刺**的量（平均帧时间会把它抹平）：首帧 9.8ms（建管线/描述符池/离屏），
稳态单帧最大 2.5ms，>20ms 的帧 0。**教训：首帧必须与稳态分开记**，否则首帧会盖住真正的尖刺
（这次差点把首帧的 9.5ms 当成"尖刺仍在"）。


## 十二、主线重启：统计量移植 + 身体程序工作点的第一轮标定

### 12.1 移植（已完成）

## 十三、能不能把果蝇大脑用 PyTorch 重写？（实测回答，2026-09-19）

先量再说。本机是装好 torch 2.9.1+cu126 的（RTX 3090 Ti 24GB），脚本 `offline_torch_probe.py`
直接吃真实的 `csr.bin`。

### 13.1 各种「矩阵表示」的规模（fp32）

| 表示 | 规模 | 结论 |
|---|---|---|
| 解剖学非零（CSR：值+列号+行指针） | **205 MB** | 就是我们现在这份 |
| h×h 稠密（每神经元一行权重） | 111.2 GB | **实测在这张卡上 OOM** |
| l×l 稠密（边上一条权重） | **2.62 PB** | 物理上不可能 |
| 边空间"每神经元一个 n×m 矩阵"块对角全填 | **15.7 GB** | 唯一放得下的稠密形态，但密度 6e-6 |

⇒ "每个神经元是一个矩阵"这个表示，**用稀疏写就是现有 CSR（205MB）；用稠密写只有 15.7GB 那种
块对角形式勉强放得下**，而它 99.9994% 是零。所以这个表示本身不构成换框架的理由。

### 13.2 每神经步实测（SpMV，不含细胞动力学）

| | ms/步 |
|---|---|
| scipy CSR 单线程 | 114.5 |
| torch sparse_csr GPU（1 只） | **0.533** |
| torch GPU（16 只批量） | 3.53（每只 0.22） |
| torch GPU（64 只批量） | **5.79（每只 0.0905）** |
| 细胞动力学 elementwise（GPU 参考） | 0.065 |

### 13.3 结论

1. **技术上能，架构上不该，性能上买不到当前需要的东西。**
   - 网络步只占每步 74ms 里的 18ms（MuJoCo 44ms 才是大头）；把大脑搬到 GPU 最多
     13.6fps → 约 18fps，**不解锁任何当前被卡住的事**。
   - 违反约束"最终要使用我们自己的 xhqm 库跑果蝇，不要额外引入新库"，而且会割裂
     "大脑—身体—视觉—渲染"这条每 20ms 一次的紧耦合回路（要么每步跨进程同步，要么整体重写）。
   - 用 PyTorch **训练/梯度优化**果蝇大脑会撞上"不要人为干涉果蝇大脑内部"——那是把外部目标函数
     塞进大脑。autograd 用来**拟合细胞参数**（对电生理）不违规。

2. **真正该用 PyTorch 的是三件离线事**：
   - **批量参数扫描**：64 只并发只要 5.79ms（每只 0.09ms），而现在的标定循环是 30s 一个点
     ⇒ 64 点扫描 ~30 秒 vs ~32 分钟。**这正是主线当前卡住的地方**（工作点没标定）。
   - **参照实现（正确性对照）**：独立第二实现，是这个项目最缺的那种对照（被自己的量具坑过 9 次）。
   - **细胞参数拟合 / 环形结构假说的小规模探索**。

3. **"环形结构生长 → 自持激活"这条假说留在 xhqm 更顺**：拓扑动态生长要每步改稀疏结构，
   PyTorch 的稀疏张量没有增量改结构的支持；我们自己的 CSR 可以增量长。

4. 若确实要 GPU 加速，正确做法是把 **GPU SpMM 做进 xhqm 自己的 tensor 后端**
   （仓库已有 tensor_backend / dispatch 分层），而不是引 torch —— 这样"用自己的库"这条不破。


## 十四、秩，而不是权重：树突亚基让信号第一次穿过深层（PyTorch 参考实现）

### 14.1 起因（概念问题）

"生物神经网络里没有权重、只有各类激活函数，而数字网络里激活函数统一、重要的是权重"。
这句话可以精确化：数字网络是生物那个模型类的**特例**——

```
数字网络:   y = f( W·x )                          f 共享且固定，信息全在 W
生物:       yᵢ = Φᵢ( x_输入集(i) )                 连接组给定，可调的是每个神经元自己的函数
两者的关系: Φᵢ(x) = f( Σⱼ wᵢⱼ xⱼ )   ← 数字网络把 Φᵢ 塌缩成"线性投影 + 共享标量非线性"
```

推论（反直觉的那条）：**阈值、τ、复位、通道配比这些"激活函数式"的旋钮，对固定拓扑的点神经元
并不增加函数类**——它们只是重参数化，改工作点不改容量。生物真正多出来的表达力在
**树突亚基**（输入到胞体之前就先非线性组合 ⇒ 秩 > 1）、分流抑制、电压依赖通道、逐边状态。

### 14.2 实现

`test/ffbo/torch_bio_brain.py`（离线参考，不进运行时）：

- 连接组**固定不学习**（权重是 buffer 不是 parameter）——生物学里布线是先天给定的。
- 每神经元的传递函数按秩 K 参数化：
  ```
  hᵢᵦ = Σ_{j∈分支b} wᵢⱼ xⱼ ;  zᵢ = Σ_b gᵢᵦ·relu(hᵢᵦ − ϑᵢᵦ) ;  sᵢ = φ_soma(zᵢ − θᵢ)
  ```
  分支按**突触前 superclass** 划分（不同突触前伙伴落在不同树突区的代理）。
- `branch_mode='identity'`（只分组、不加非线性）在数学上严格等于 K=1 —— 当作对照。

### 14.3 结果（刺激注入 ol_sensory，判据 |Δ|>3σ 经验方差+AR(1)；格内 = 显著数/假阳性期望）

| 配置 | ol_intrinsic | visual_proj | cb_intrinsic | descending | 稳态活动 |
|---|---|---|---|---|---|
| K=1 点神经元 sg=16 | **0** / 241 | 0 / 25 | 0 / 87 | 0 / 4 | 0.00 |
| K=1 sg=128（增益×8） | **0** | **0** | **0** | **0** | 0.00 |
| K=1 sg=1024（增益×64） | **0** | **0** | **0** | **0** | 0.00 |
| K=8 仅分组·无分支非线性 | **0** | 0 | 0 | 0 | 0.01 |
| K=4 分支整流 | 286 | 66 | 227 | 14 | 0.01~0.08 |
| **K=8 分支整流** | **1821**（7.6×） | **405**（16×） | **1320**（15×） | **136**（34×） | 0.02~0.14 |
| K=8 分支整流 sg=4（压增益） | **3039**（12.6×） | 750（30×） | 2366（27×） | 240（60×） | 0.02 |

**全部对照（标签随机化）在每一格都是 0。**

排掉三种混淆：
1. **不是增益**：点神经元增益拉 64 倍，深层仍全 0。
2. **不是"分组"本身**：K=8 只分组不加非线性 ⇒ 与 K=1 逐位相同（全 0）；这条同时验证了两条代码路径等价。
3. **不是工作点被推高**：各配置稳态活动同量级（0.00~0.14），信号却差三个数量级。

唯一变化量 = **非线性落在分支（输入侧）还是只落在胞体（输出侧）**。且单调随秩
（0 → 286 → 1821），压增益反而更通（sg=4 > sg=16，与"越饱和越传不过去"一致）。

### 14.4 对主线的两个后果

1. **解释了老结论**：xhqm 跑的是点神经元（先求和、后一次非线性），所以我们扫的那约 20 个工作点
   （增益/阈值/τ/5 种通道/分级或脉冲）**全都坐在求和之后**，按本对照**原理上修不好**。
   与 9.3/10 节"逐级驱动稀释是秩-1 瓶颈"一致。
2. **第十节那条"只能读视叶状态、用解码器凑"的判定可能不再必需**：K=8 时信号已到达
   descending_neuron（136 显著 vs 期望 4）。若把树突亚基补进 xhqm 的细胞后端，解剖学通路
   也许能自己走通，不必绕道解码器。

### 14.5 边界（必须说清）

- 这里的树突是**最小代理**（按突触前*类型*分组 + 每分支增益/阈值 + relu）；真实树突按**位置**
  分组、有电压依赖电导。所以证明的是**机制类别**成立，不是"这个具体模型是对的"。
- 本参考实现活动水平（0.00~0.14）远低于 C++ 程序的 16~20%，**数值只在本文内部横向可比**。
- 与 C++ 的**跨实现一致**：两边都是点神经元时，刺激都传不出视叶 —— 两个独立实现同向。
- 尚未涉及行为：还没接到身体/转向。


## 十五、行为判据设计：把「果蝇对外界做出反应」写成可证伪的量

主线的目标句是"果蝇接受环境信息后自己决策、对外界做出反应"。但程序现在只打印一个
**左右驱动差**（实测 ~1e-3，且相位随机化前后逐位相同 ⇒ 与刺激无关），**末位置单点**也不可靠
（它依赖 `--sec` 长度，我自己就因此误判过一次）。这不构成可证伪的判据，必须重新设计。

### 15.1 刺激（自变量）

沿用已有：`--predator` 的逼近/远离相位（loom）。要求：
- **相位触发随机化**（随机块长），不能与固定周期绑定 —— 第 7 条纪律：周期性标签会与网络自身
  振荡锁相，实测能把 d′ 做成 304（而幅度 0 对照也是 304）。
- 必须有**幅度 0 的同参数对照**（同一个世界、loom 关闭），不是"另跑一次关掉刺激"。

### 15.2 行为读出（因变量）

三级，都要连续量、都要能算显著性（与神经统计同一套：经验方差 + AR(1) + 假阳性期望）：

1. **转向**：左右驱动差 `Δdrive = right − left`，按刺激相位分组取均值差。
   注意要先确认符号约定（正 = 右转），且用**归一化**量（除以总驱动），否则只反映整体兴奋度。
2. **位移**：刺激窗口内相对刺激方位的**速度投影**（趋近为正），而不是末位置单点。
   逐帧 qpos 差分 → 投影到"指向暗物的水平方向"。
3. **驻留/逃逸时序**：从刺激出现到出现一次可分辨转向的**潜伏期**分布。

### 15.3 对照（必须能推翻结论，四类齐全）

| 对照 | 做法 | 期望 |
|---|---|---|
| 标签随机化 | 相位标签打乱（已有 `--label-random`） | 行为差 ≈ 0 |
| 刺激幅度 0 | 同参数、loom 关闭 | 行为差 ≈ 0 |
| 瞎眼 | `--vis-off`（视觉注入关掉） | 行为差 ≈ 0（若不为 0，说明是别的通路在起作用，结论无效） |
| **强正对照** | 直接给运动神经元注入左右不对称电流 | **必须测出行为差** —— 否则"测不出"可能只是行为读出太钝 |

最后一条最关键：**没有正对照，"没测出反应"与"读出器坏了"无法区分**。本项目已经栽过
9 次量具问题，这一条不能省。

### 15.4 采样与判据

- 单次 ≥ 30 s（第 2 条纪律：2 秒标签需 ≥30 s）；至少 3 次独立种子/trial，报分布不报单点。
- 判据：行为差 > 3σ（AR(1) 修正后），**且四类对照全部落在噪声底附近**；
  正对照必须同时显著（证明读出器有效）。
- 报"效应量"（差 / 对照标准差），不只报显著性。

### 15.5 与两条路线的接口

- **解码器路线**（第十节）：读出视叶状态 → 转向指令。此时行为**依赖解码器权重**，
  所以解码器必须用"一半估权重、另一半评估"的交叉验证，否则 d′ 乐观偏置。
- **树突路线**（第十四节，子智能体在做）：若秩-K 让解剖学通路自己走通，则行为**不依赖解码器**，
  直接从网络自身动力学长出来 —— 更贴合"不要人为干涉果蝇内部"这条判据。
  两条路线共用本文的行为判据与四类对照，所以先把判据建起来，谁先走通都能用。


## 十六、行为判据的实测校准：正对照逼出"统计单位错了"

第十五节设计了判据，本节是**把它跑起来后的实测**。结论：判据的第一个版本没有功效，
是靠正对照才发现的。

### 16.1 正对照 `--asym-motor A`

只在「很近」相位给左右 actuator 注入 ±A/2。**作用点在 actuator 侧（大脑下游），
不是"干涉果蝇大脑内部"，而是校准测量链**：判据若能测出这个已知的、与刺激锁相的转向信号，
"测不出反应"才是有效结论；顺带给出这套读出的**灵敏度下限**。

实测（`--sec 30 --predator --syn-gain 16 --graded-base 2.0`）注入量与均值差：

| A | 很近均值 | 很远均值 | 差 | 期望差 |
|---|---|---|---|---|
| 0.00 | -0.000844 | -0.000216 | -0.000627 | 0 |
| 0.02 | +0.018283 | -0.000274 | +0.018557 | 0.02 |
| 0.05 | +0.046400 | +0.000274 | +0.046125 | 0.05 |
| 0.10 | +0.093186 | +0.001030 | +0.092156 | 0.10 |

⇒ **注入是准的**（均值差线性跟随，误差 <1%）。

### 16.2 但第一版检验几乎没有功效（正对照发现的）

同一批数据算 AR(1) 修正后的 z：A=0.02 → z=+0.20；A=0.05 → z=+0.51；**A=0.10 → z=+1.02**。
注入了 Δ=0.092 的真实转向，检验却说"不显著"。

原因：左右驱动差被 **4 Hz 步态正弦**主导，逐步样本强自相关 ⇒ AR(1) 折算后 n_eff 只剩几十，
SE ≈ 0.09，于是 0.092 的效应只有 ~1σ。
注意"窗口长度取步态周期整数倍"**只保证均值无偏，不解决方差** —— 这条以前没暴露，
是因为旧的 `rep()` 只报均值差、根本没有标准误。

### 16.3 修法：统计单位从「神经步」改成「步态周期块」（已实施并校准）

先算块（2 个步态周期 = 25 步 @dt=20ms、4Hz）内的均值，块间近似独立，再在**块均值**上做两相检验；
**整块不同相位的块丢弃**（避免相位归属含混）。

修好后的正对照校准（`--sec 30 --predator --syn-gain 16 --graded-base 2.0`）：

| 注入 A | 两相均值差 | z | 判定 |
|---|---|---|---|
| 0（无注入） | -0.000627 | **-0.65** | 不显著 ✓（正确地报"没有与刺激锁相的转向"） |
| 0.02 | +0.018557 | **+20.61** | ★ 检出 |
| 0.05 | +0.046125 | **+7.15** | ★ 检出 |
| 0.10 | +0.092156 | **+12.02** | ★ 检出 |

⇒ **行为判据现在是校准过的仪器**：
1. 基线正确地说"没有"（z=-0.65），不是把噪声读成反应；
2. 最小测试幅度 A=0.02（归一化左右驱动差 Δ≈0.019）就能检出 ⇒ **灵敏度下限 ≤ 0.019**。
3. 30s 只拿到 21/24 个块样本，功效受运行长度限制 ⇒ 正式结论要件数 ≥3 次独立 trial（见 15.4）。

诚实的边界：z 不随注入幅度单调（20.6 / 7.2 / 12.0）——块级方差逐次不同，注入与步态动力学也有交互。
所以"检出与否"可信，**"z 的大小"不能当剂量-反应曲线用**。

### 16.4 并行改同一个头文件的代价（实测教训）

我把秩-K 移植交给子智能体、它要改 `cell_backend.h`，而 `fly_mcns_view.cpp` 也 include 这个头文件。
我全程不构建以避开 ABI 陷阱，但最后为了验证本节改动仍必须构建 —— 而当时**子智能体正在写
第 1 步逐位 dump 的代码（用了 `B.dbg` 但成员声明还没加）**，构建直接失败：
`error C2039: "dbg": 不是 "cellbackend::bio" 的成员`。

**教训**：并行分工时，"只读的共享头文件"也是共享写资源。要么在开工前把共享头文件切成
互不相交的部分，要么约定"谁改头文件谁负责在其间不构建"，且**验证必须排到对方收工之后**。

### 16.5 现在的判据能说什么、不能说什么

- **能说**：给果蝇看"很近/很远"两种刺激，若它的**左右驱动差**在两相之间给出 |z|>3，
  那就是一个与刺激锁相的转向信号；反之（如基线 z=-0.65）就是"在这个灵敏度下没有"。
- **不能说**：z 的大小不是效应量；要报效应量请用两相均值差（如 A=0.02 对应 Δ=0.019）。
- **判据成立的前提**：正对照必须同时跑通（证明读出器有效）。正对照注在 actuator 侧、
  不进大脑，所以不违反"不要人为干涉果蝇内部"。
- 尚未跑的两类对照：**刺激幅度 0（loom 关）** 与 **瞎眼 `--vis-off`**。跑通它们之后，
  才轮到用这套判据去判"果蝇自己有没有反应"。


## 十七、刺激段长检验（打在主线身上的一次混淆排查）与收敛的结论

### 17.1 起因

子智能体在 `mcns_net` 上做同细胞模型对齐时，查出**刺激段长是独立于细胞模型的一个开关**：

```
--rev-block 0.8s（≈40 步）  ol_intrinsic 62 显著
--rev-block 2.0s（≈100 步） ol_intrinsic 7206，且深层四层全部点亮
```

而我们的身体程序 `fly_mcns_view` 的两相窗口 = `0.375×T` = **1.5 s**（T=4s），正好夹在
"失败 0.8s" 与 "成功 2.0s" 之间 ⇒ **必须验**，否则"信号出不了视叶"可能只是刺激太短。

为此给身体程序加了 `--loom-period T`（两相窗口 = 0.375T；约束：窗口须为步态周期 0.25s 的
整数倍 ⇒ T = 2m/3，m=6→4.0s、m=8→5.333s、m=12→8.0s）。

### 17.2 结果（bio + 分级链，`--sec 40 --predator --syn-gain 16 --graded-base 2.0`）

| loom 周期 | 窗口 | ol_intrinsic 显著 | visual_proj | cb_intrinsic | descending | vnc_motor | 全网/假阳性期望 |
|---|---|---|---|---|---|---|---|
| 4.0 | 1.5 s | 524 | 1 | 0 | 0 | 0 | 530 / 280 |
| 5.333 | 2.0 s | 592 | 2 | 0 | 0 | 0 | 595 / 280 |
| 8.0 | 3.0 s | **828** | **12** | 1 | 0 | 0 | 843 / 280 |

行为读出（左右驱动差两相 z）：+0.15 / −0.20 / +0.57 —— **全部是噪声**。

⇒ **加长刺激窗口确实推高视叶（1.9× → 3.0× 底噪），但打不开深层**（cb_intrinsic / descending /
vnc_motor 仍为 0~1）。

（一条自查记录：第一遍跑漏了 `--cell-model bio --bio-graded`，落到默认 LIF 上，
`ol_intrinsic 有发放` 从 67023 变成 36777、显著数掉到个位数 —— 与历史数字不可比。
已重跑。**又一次证明"看起来合理的数字"必须与历史基线对表**。）

### 17.3 收敛的结论

两条独立路线在这一点上会合：

| 证据 | 结论 |
|---|---|
| `mcns_net` 同细胞模型对齐（子智能体）：K=1 深层全 0；K=1 增益×8/×64 仍全 0；K=8 整流四层全亮 | **是"秩"在起作用，增益不能替代** |
| 身体程序刺激段长扫描（本节）：1.5s→3.0s 视叶变强、深层仍暗、行为 z≈0 | **刺激时长不是主线的瓶颈** |

⇒ **主线的瓶颈是每个神经元的传递函数秩**（点神经元：先求和、后一次非线性），
与刺激长短、增益大小都无关。这同时回收了本项目此前约 20 个工作点全失败的解释：
它们都坐在"快刺激 + 点神经元"上，而**点神经元那条腿本来就是断的**。

### 17.4 因此主线有两条路，需要选

- **(a) 解码器路线**（第十节）：读视叶状态 → 转向指令。**现在就能走**（视叶信噪比 166×，
  行为判据已校准，基线正确地报"没有"）。代价：行为有一部分由解码器权重决定，
  要严格用"一半估权重、另一半评估"的交叉验证。
- **(b) 秩-K 路线**：把已验证的树突亚基接进身体程序，让解剖学通路自己走通。
  架构上更贴合"行为从系统自身动力学长出来"。**前置条件**：子智能体下一步要验的
  **bio 后端 + 2s 刺激**下 K 是否也能穿深层 —— 若 bio 不行而只有 `cur` 行，
  就得考虑运行时后端是否换成电流型（那是更大的改动，要先议）。


### 17.5 分叉解决：**(b) 关闭，(a) 是唯一走得通的路**

子智能体第四轮验了 (b) 的前置条件（bio 后端 + 2s 刺激），结果是否定的：

| 配置 | ol_intrinsic | visual_proj | cb_intrinsic | descending | 稳态 |
|---|---|---|---|---|---|
| K=1 | 6495/176 (对7) | 62/4 (对3) | 1/0 | 0/0 | 0.010 |
| K=8 identity | 6495/176 (对7) | 62/4 (对3) | 1/0 | 0/0 | 0.010 |
| K=8 整流 | 3126/173 (对27) | **0/4 (对5)** | **0/0** | **0/0** | 0.015 |
| K=1 增益×8 | 4181/222 (对82) | 304/19 (对34) | 463/72 (对7) | 33/3 (对2) | **0.365** |

- K=8 深层全在噪声底（`visual_projection` 的**对照 5 > 显著 0**），而 **K=1 的 62 反倒更好**。
- bio 的 K=1 拉增益能"深层亮"，但**稳态被从 0.000 抬到 0.365** ⇒ 与"工作点被推高"分不开
  （第十节那个老问题重演，不能算独立证据）。
- **不是驱动不够**：K≥2 把稳态 0.291→0.391 却仍穿不过 ⇒ bio 的电导机制吃掉了输入侧非线性的收益。

⇒ **秩-K 只在电流型 `cur` 上成立，而 `cur` 不是运行时后端** ⇒ (b) 需要换运行时细胞模型
（比加树突更大的改动），**本轮决定不做**。**(a) 解码器路线成为唯一可行路**，其证据是齐的：
视叶信噪比 166×（工作点 `graded-base=2.0`）、行为判据已校准（基线 z=-0.65、灵敏下限 ≤0.019）。

顺带回收的教训：**"某个工作点下深层亮了"必须同时报稳态活动**，否则分不清"信号穿透"与
"工作点被推高"——本项目在第十节栽过一次，这次靠稳态列当场识破。

### 17.6 另外两条（子智能体第四轮修好的）

- **NaN 根因是显式欧拉失稳，不是"某个数太大"**：合并同类项后 `v' = (1 − dt/τ − dt·Σg)·v + …`，
  稳定充要条件 `Σg < (2 − dt/τ)/dt`；dt=0.02、τ=0.1 ⇒ **Σg < 90**，实测 Σg≈1283 ⇒ 系数 −24.9，
  每步放大 25 倍并翻号。修法：总电导按比例缩到 0.9×81（不改通道配比）。
  记档的三个半成品守卫：上限 2e2 / 1e4 **都高于稳定边界 90**，钳了照样发散；只钳单通道也不行
  （约束的是总和）。**这条教训通用：显式积分的稳定性约束是"总和"的，不是"单个量"的。**
- `--cells` 逐步 dump 仍不入库，但现象/复现步骤/已排除因素都留档（最可疑是当时 `dbg_want[i]`
  在空 vector 上越界读造成的 UB）："重做时先 `#if` 隔离、每加一层跑一次回归对照"。


## 十八、(a) 解码器闭环的规格（下一步实施）

目标：让果蝇的转向**经由它自己的视叶状态**依赖外界，并用已校准的判据证明它成立。

### 18.1 结构

```
外界 loom → raycast/光感受器 → 视叶（ol_intrinsic）状态 s_ol
                                        │
                                        ├─ 解码器 w（只读，不写入大脑）
                                        ▼
                                  dec = Σ_i w_i·s_i
                                        │
                                  固定读出增益 k
                                        ▼
                        左右 actuator 不对称（右 +k·dec~ / 左 −k·dec~）
```
- **解码器只读**：不向网络注入任何东西，因此不违反"不要人为干涉果蝇大脑内部"。
- `dec~` = `dec` 减去其在评估段上的均值（去掉共模，只留与刺激相关的分量）。

### 18.2 反乐观偏置（必须）

- 权重 `w` 用 **Fisher 判别方向**：`w_i ∝ (mean_on,i − mean_off,i) / var_i`，**只在前半段估**。
- 行为判据**只在后半段评估**（前半段不注入转向，或注入但不计分）。
- 报"前半估的 w 在后半的判别力"与"后半估的 w 在前半的判别力"两个方向（交叉验证）。

### 18.3 对照（缺一不可）

| 对照 | 做法 | 期望 |
|---|---|---|
| 基线 | `k=0`（已测） | z=-0.65，不显著 ✓ |
| 标签随机化 | 相位标签打乱后再估 w | 行为 z 不显著 |
| 瞎眼 | `--vis-off` | 视叶无响应 ⇒ 行为 z 不显著 |
| 正对照 | `--asym-motor`（已测） | z≫3 ✓，灵敏度下限 ≤0.019 |
| **打乱状态** | 把 `s_ol` 在时间上循环移位后解码 | 行为 z 不显著（证明不是"任何输入都能转出方向"） |

### 18.4 判据

后半段评估窗口上，行为两相 z > 3，且上表四类对照全部不显著；同时报效应量（两相均值差）。


## 十九、(a) 解码器闭环：实现与实测（未达判据，但链路已通）

### 19.1 已实现（`fly_mcns_view.cpp`）

```
外界 loom → raycast/光感受器 → 视叶 s_ol
                                   ├─ 权重 w：只在【前半段】估（Fisher 方向 + 岭 + 只留判别力前 256 个细胞）
                                   ▼
                             dec = Σ w_i·s_i − dc_mA      （减掉估计段共模）
                                   ├─ 只在【后半段】施加
                                   ▼
                        左右 actuator 不对称（右 +gain·dec / 左 −gain·dec，限幅 ±0.25）
```
- **只读**视叶状态、不向网络注入 ⇒ 不违反"不要人为干涉果蝇大脑内部"。
- 估与评分开（前半估、后半施加）⇒ 反乐观偏置。

### 19.2 新增的自检：命令自身的信噪比（关键）

光看行为分不清两种情况：**"解码器在噪声里读"** 与 **"身体不响应命令"**。
所以额外统计**施加量 d 自己在两相之间的 z**：

| 配置 | 命令自身 z | 行为 z |
|---|---|---|
| gain=20，`--sec 50` | −3.23 ★ | −1.21 |
| gain=20，`--sec 100` | **+4.31 ★** | +1.05 |
| 置换权重（**无效**对照，见 19.3） | +3.28 ★ | +0.34 |
| 估计标签随机化（**有效**零假设） | **−0.82** ✓ | （块被清空，见 19.4） |

⇒ 命令确实带相位信息（z=4.31），**链路是通的**；但行为还没到判据。

### 19.3 ★ 一个不成立的对照：置换权重

原以为"把 w 随机置换"能当零假设。实测 **z=+3.28，照样"显著"** ⇒ 该对照**无效**。
原因：视叶群体本身广泛相位调制（群体 d′ ~280），**任何随机权重和都会沾到共模信号**。
⇒ 有效零假设必须是**打断权重与标签的对应**（用随机标签估 w），见 19.4。

**教训**：零假设要打在"被检验的那条联系"上。"打乱权重"打乱的是**空间**对应，
而共模信号在空间上是处处存在的 ⇒ 打不断。

### 19.4 有效零假设与一个待修的报告路径

`--label-random`（估计用的 on/off 标签随机化）下：|w| 归一化前 21.5 → **7.16**（拟合明显变弱）、
**命令自身 z=−0.82**（不显著）⇒ 零假设成立 ✓

但行为那一行变成"样本不足 (0/0)"：因为块统计要求**整块同相位**，而标签随机化后每步相位标签
被随机翻转 ⇒ 永远凑不出纯块。**行为侧的对照报告需要另一条路径**（例如按真实相位分块、
但用随机标签估的 w 施加），这条待修。

### 19.5 行为为什么还没到判据（诊断）

同一 run（gain=20，sec 100）：命令的两相均值差 +0.047、块级 se ≈0.011；
行为的两相均值差 +0.060、块级 se ≈**0.058**。

⇒ 行为的均值差是对的（甚至更大），**但块级噪声是命令噪声的 5 倍**。
原因：注入量很大（平均 −0.117、且逐块波动），身体忠实地跟着这个带噪命令转，
行为读出的块间方差被抬起来，把相位锁定的那部分淹掉。

（对照参考：正对照 `--asym-motor 0.02` 是**阶跃**注入，两相差 0.0186 就得到 z=20.6，
块级 se 只有 0.0009 —— 差别正是"阶跃 vs 带噪连续"。）

### 19.6 下一步（按代价排序）

1. **扫更低的 gain**：命令 z 与 gain 无关（同步缩放），而行为噪声随注入幅度上升
   ⇒ 存在一个让行为 z 最大的中间幅度。
2. **给命令低通**（命令平滑到 ~100ms 尺度），压掉逐块波动。
3. 修 19.4 的行为侧对照报告路径。
4. 跑满第十五节要求的四类对照（刺激幅度 0、瞎眼 `--vis-off`）。


## 二十、每类死区自稳：机制、τ 扫描与两条结论

### 20.1 动机（来自实测，不是设计偏好）

给每类加上均值活动与范围这两列之后，看到的是这个：

| 类 | 均值活动 | 范围 |
|---|---|---|
| ol_sensory | 0.485 | 0.326~0.639 |
| ol_intrinsic | 0.393 | 0.001~0.531 |
| visual_projection | 0.081 | 0.001~0.520 |
| **cb_intrinsic / descending / vnc_* / ascending / centrifugal** | **全部 0.023~0.025** | **全部 0.001~0.06~0.075** |

十个不同解剖类的均值挤在同一处、上限几乎相同 ⇒ 它们被钉在同一个极低静息值上，输入几乎不改变输出。
**这就是"逐级驱动稀释"的真身**：深层根本没进入敏感区。而工作点此前只能靠一个**全局常数**
（`graded-base`）手调 —— 0.5 时对照炸到 162、2.0 时对照 9。一个全局旋钮同时决定所有类的动态范围，
这在生物学上就不对。

### 20.2 机制

每细胞一个兴奋性倍率 `h_i`（乘在突触电导上），按**类**的慢平均活动与死区比较后缓慢增减：

```
若 m_c < lo:  h_i *= (1 + dt/τ)     （i ∈ 类 c）
若 m_c > hi:  h_i *= (1 − dt/τ)
带内不动；h 钳在 [0.02, 200]
```
- **自校准**：目标不是手填的每类数值，而是"落在带内就不动"。手填 20 个常数正是当前问题的来源。
- 生物学对应内在可兴奋性调节 / 稳态可塑性。
- 正向副作用：把总电导压在显式欧拉稳定界内（第十七节那个 NaN）。
- 默认 `τ=0` ⇒ 完全不生效，旧路径逐位不变。

### 20.3 τ 扫描（`--sec 120`，死区 [0.05,0.50]；括号内 = 显著数 / 该类自己的假阳性期望）

| 类 | τ=0（关） | τ=0.5 | τ=2 | τ=20 |
|---|---|---|---|---|
| ol_sensory | 260 (16×) | **1890 (115×)** | 1783 (108×) | 1149 (70×) |
| ol_intrinsic | 202 (1.1×) | 201 (1.1×) | 203 (1.1×) | 200 (1.1×) |
| visual_projection | 0 | **38 (2.8×)** | 13 (0.9×) | 13 (1.0×) |
| cb_intrinsic | 3 (0.07×) | 3 (0.05×) | 3 (0.05×) | 5 (0.08×) |
| vnc_intrinsic | 0 | 41 (1.5×) | 5 (0.2×) | 3 (0.1×) |
| descending | 0 | 4 (1.25×) | 0 | 1 |
| **深层均值活动** | 0.022 | **0.099~0.132** | 0.087~0.113 | 0.030~0.047 |
| **范围上限（饱和迹象）** | 0.06 | **0.98** | 0.93 | 0.35~0.54 |

★ **口径提醒**：每类必须与**该类自己的**期望（该类有发放细胞数 × 0.27%）比。用全网期望去比
某一类会严重高估比值（本节与前面几处都踩过）。另外"信号/标签随机化对照"与"信号/解析期望"
是两个不同的量，前者是本项目更硬的那个（AR(1) 修正偏保守，实测对照常低于解析期望）。

### 20.4 结论一：机制成立，死区按设计工作

- **深层的十类被从 0.022 抬进带内**（τ=0.5/2 → 0.09~0.13），并招募更多细胞进入活动
  （cb_intrinsic 有发放 15141 → 23630）。
- **带内的类完全不受影响**：ol_intrinsic 在四个 τ 下都是 0.384、显著 200~203
  —— 死区没有动不该动的东西。（这也是一条很强的内部一致性检验。）

### 20.5 结论二：我上一轮的预测**错了**，而且错得有意义

预测是"短 τ 会把 looming 当漂移抹掉"。实测相反：**τ=0.5 时感觉层信噪比 16× → 115×**
（260 → 1890），`visual_projection` 0 → 38（2.8×）。

原因：把某类的**均值**管得更紧 ⇒ 跨细胞方差变小 ⇒ **同样的调制量变得更显著**。
所以自稳在这里**帮了读出**。
（但"自稳会不会把刺激一起稳压掉"的严格检验仍需要一个**非死区的比例控制器** —— 那个按设计
应当吞掉 looming。本节不能替代它。**待做**。）

### 20.6 结论三：边界被实测确认 —— 自稳摆工作点，不创造信号

`cb_intrinsic` 工作点已进带（0.1119），显著数仍只有 **3，而期望 64（0.05×）**；
`descending` 4 vs 期望 3.2。**深层工作点对了，依然没有相位信息。**

⇒ 负反馈解决"类在哪儿"，不解决"类有没有信号"。后者要靠驱动集中（输入侧结构/秩），
而那条路在 bio 后端已被第十七节否掉。

### 20.7 τ 的取舍（可直接用）

| τ | 行为 | 判断 |
|---|---|---|
| 0.5 s | 抬得最猛，但**冲饱和**（部分细胞到 0.98） | 次优：把"太低"换成了"太高" |
| **2 s** | 抬到位且饱和较轻（0.93） | 本轮窗口内最优 |
| 20 s | 温和无饱和（上限 0.35~0.54），但 120 s 只够 6 个时间常数、没抬完 | 需更长跑，或调到 5~10 s |

### 20.8 待做（按我判断的优先级）

1. **紧张性旋钮**：现在的自稳只乘突触电导，**对输入为 0 的细胞乘以任何增益仍是 0**
   （实测佐证：cb_intrinsic 的 h 涨到约 20×，输出只从 0.025 到 0.043）。
   要把"输入几乎为 0、进不了响应区"的类抬起来，需要同时调**静息点/紧张性激励**。
2. **非死区比例控制器**作为对照，检验"自稳会不会吞掉刺激"（20.5 的待做）。
3. 用**信号/标签随机化对照**（不是解析期望）复跑本节关键两列。
