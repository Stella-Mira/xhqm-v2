## ★★ 结论（r579，最新）

**同细胞模型对齐实验做完了：C++ 复现了参考的结论 —— 秩-K 是让信号进入深层的开关。**
而且顺带查出一个**比细胞模型更要紧的混淆：刺激的段长**（0.8 s 的块方波下这个效应会被抹平）。详见 §4。

**但把同一套 2 s 刺激用到默认后端（bio 电导型）上，K=8 仍然穿不过深层**（§4.4b）——
**只有电流型后端能穿**。另外 NaN 已修（§5），`--cells` 的未定位现象已留档（§7b）。

## ★ 修订记录（r571 之后，第二轮）

**r571 版里有一个真 bug，它把第一轮的结论带偏了。** 本轮找到并修掉：

| | r571（错） | 本轮（已修） |
|---|---|---|
| 抑制边（w<0）的贡献 | `+|w|·mod·s` —— **符号被吃掉又还原了一次** | `w·mod·s`（带符号） |
| K=1 路径 | `w·s`（正确） | `w·s`（逐位不变） |
| `--dend 8 --dend-identity` 与 K=1 | 数学上等价、实际**完全不同**（1335 vs 164 显著） | **逐位相同**（见 §2） |
| 第一轮对差异的解释 | 「这个网络对浮点加法次序敏感」 | **错误**。差异是抑制边整体反号，与浮点次序无关 |


根因：`w_abs = has_mod ? (fabs(w)*mod[b]) : w` 在 K>1 时丢掉了 w 的符号，而外面那句
`gsum[ci] += (w>=0 ? w_abs : -w_abs) * sk` 又按 w 的符号取了一次反 —— 两次操作在 K=1 时互相抵消
（`w_abs = w` 带符号 ⇒ 还原正确），在 K>1 时就只剩一次取反 ⇒ **抑制边整体反号**。
第 0 步 `gsum[CH_FAST_INH]` 就从 −0.2058 变成 +0.2058，两条轨迹当场分岔。

为什么第一轮没抓到：我只用**静态驱动自检**（同一个 `s` 下比**总和**）判等价，
而那个总和里抑制与兴奋混在一起，恰好把单通道反号抵消掉了。
**教训：等价性判据必须分通道、而且要逐步入。** 本轮给 `--dend-drive-check` 加了「抑制半边单独比」
（`mx_neg`），它会当场报 `1.000e+00`（反号）而不是 `0.000e+00`。

## 0. 开关

| 开关 | 作用 |
|---|---|
| `--dend K` | 秩-K 分支（默认 1 ⇒ 点神经元，与加这个功能之前行为相同） |
| `--dend-identity` | 只分组、不加分支非线性（`z = Σ_β g_β h_β`，数学上严格等于 K=1，用作对照） |
| `--dend-seed S` | 分支阈值 ϑ 的随机流种子 |
| `--dend-drive-check` | 量具自检：同一个 `s` 下，逐边求和 vs 分支路径的驱动差多少（含抑制半边） |
| `--inject-class <superclass>` | 按解剖分区注入（参考实现用 `ol_sensory`；数据目录的 groups.txt 里没有这个组） |

模型（照参考实现）：

```
h_iβ = Σ_{j∈分支β} w_ij x_j
z_i  = Σ_β g_iβ · relu(h_iβ − ϑ_iβ)
s_i  = φ_soma(z_i − θ_i)          ← 胞体那条路径原封不动（LIF / 分级链仍在它后面）
```

分支划分：每个神经元把入边按**突触前 superclass** 分组，入边里最多的 K−1 种各占一个分支，其余归分支 0。
每条边恰好属于一个分支（实测覆盖边数 = 非零元数 25,582,938）。`g` 初值 1、`ϑ ~ U(−0.1, 0.1)`
（实测 ϑ∈[−0.1000, 0.1000]）。

## 2. 量具自检（这一轮的关键）

`--dend-drive-check`：固定同一个 `s`，对全部 166,700 个神经元算两个驱动，并且**分通道**比：

|---|---|---|---|

| K=8 relu | 7.595e+06（分母极小的细胞） | **1.000e+00** | 抑制半边被整段改写 ⇒ 分支非线性确实在起作用 |

「稳态」= 后半程平均输出。

## 4. 同细胞模型对齐实验：**C++ 复现了参考的结论**（r577）

### 4.0 起因：两边的旧结论互相矛盾

| | PyTorch 参考（电流型 + clamp 输出） | C++ bio（电导型 + 5 通道 + 44.8% 抑制） |
|---|---|---|
| K=1 深层 | 全 0 | 全 0（工作点 C）；A 点 ol_intrinsic 有 1335 |
| K=1 增益 ×8 / ×64 | 全 0 | **×8 就能给 visual_projection 59/23** |
| K=4 / K=8 整流 → 深层 | 405 / 750（vis）、1320 / 2366（cb）、136（desc） | **全 0（≤ 假阳性期望）** |

两个结论不可能同时对。要么是「秩」在起作用，要么是**细胞模型**在起作用 —— 只有放到同一个细胞模型下才能判。

### 4.1 做法：`--cell-model cur`（与参考严格同构）

`cell_backend.h` 新增 `cur_mode`（默认 0 ⇒ 老路径逐位不变），只做参考 `BioBrain._drive` 做的事：

```
h_i = Σ_k w_k·s_k            （权重即电流；w 已含 syn_gain —— 与参考的 val*syn_gain 同一语义）
v_i ← (1 − dt/τ)·v_i + dt·(h_i + i_ext_i)
s_i = clamp(v_i, 0, 1)       （所有细胞都走这一支，与参考的 graded 一致）
```

**没有 I_bg、没有噪声、不接通道/电导**（参考就是没有）。开关：`--cell-model cur`
（可选 `--cur-alpha` = dt/τ、`--cur-ki` = dt）。

**标定记录（不是调参调出来的，是量纲对齐）**：

| 量 | 参考的方程 | 本处 | 取值依据 |
|---|---|---|---|
| 膜电位保留比例 | `v + (−v/τ)·dt` ⇒ `(1 − dt/τ)·v` | `(1 − cur_alpha)·v` | cur_alpha = dt/τ = 0.02/0.1 = 0.2 |
| 驱动系数 | `+ I·dt` | `+ cur_kI·I` | cur_kI = dt = 0.02 |
| 输出 | `clamp(v, 0, 1)` | `clamp(v, 0, 1)` | 一致 |

★ **踩过的坑**：第一版把 `cur_kI` 写成 1.0（**丢掉 dt 因子**），v_ss = kI·I/(dt/τ) 比参考高 1/dt = 50 倍，
整网被顶到 clamp=1 饱和（稳态 0.99 而参考 0.02~0.14）。那是**量纲错**，不是「两边工作点不同」。
改对之后 K=1 的稳态就和参考对上了（见 4.3）。

★ **K=1 的标定判据（唯一硬指标 = 稳态活动量级可比）**：
参考 K=1 `ol_sensory` 刺激期均值 0.124、深层 0.000；C++ cur K=1 `ol_sensory` 稳态 0.067、深层 0.000。
两边的注入标定也一致：参考 `I:amp=1.5` ⇒ v_ss = τ·I = 0.15；C++ `cur_kI·1.5/(1−α) = 0.15`。**同一工作点。**

### 4.4 三条判据的明确回答（**cur 侧**）

1. **同细胞模型下，C++ 能否复现「秩-K 让信号进入深层」？→ 能。**
   K=1（以及 K=1 拉增益、K=8 identity）深层全 0；K=4/K=8 整流时四层全部远高于假阳性期望，
   对照全部为 0。与参考**定性完全一致**、量级同阶（ol_intr 7206 vs 1821、vis 567 vs 405、
   cb 15797 vs 1320、desc 434 vs 136）。
   （一处**不一致**要记下来：参考随 K 单调增（286→1821），C++ 不是（K=4 的 ol_intr 11186 > K=8 的 7206）。）
2. **同细胞模型下，K=1 拉增益能否也把信号送进深层？→ 不能。**
   ×8 与 ×64 都是深层全 0，与参考**完全一致**。
3. **两边稳态活动量级可比吗？→ 可比。**
   ol_intrinsic 0.021 vs 0.025、visual_projection 0.025 vs 0.041、cb_intrinsic 0.146 vs 0.041、
   descending 0.036 vs 0.136 —— 都在 0.01~0.15 这一档，没有一边饱和（1.0）也没有一边静默（0.000）。

## 5. NaN：**已修**（根因是显式欧拉的稳定性条件，不是一个"太大的数"）

复现：`--sec 2 --syn-gain 480 --cell-model bio --bio-graded --graded-base 0.7 --graded-amp 4
--inject visual_R1_8 80`（**K=1 默认路径同样出现，与本功能的树突无关**）
⇒ 修前 `ol_sensory` / `ol_intrinsic` 读数全 NaN、R1-6 里 3262/3377 是 `-nan(ind)`，共 **23 行 NaN**。

**哪个量先溢出**（用「逐步检查 `isfinite(v)`」的临时探针抓到，探针已删）：**最先溢出的是 `v`**，
触发通道是 `CH_FAST_INH`：

```
NANSRC i=120302  g=0.0033 0 105.8 0 0 | gc=0 0 1177 0 0 | gsum=0 0 1707 0 0 | v=-inf out=0 cur=0.7
NANSRC i=115271  g=0 0 118.4 0 0       | gc=0 0 1324 0 0 | gsum=0 0 1920 0 0 | v=-inf out=0 cur=0.7
```

**机理（不是"某个数太大"，是积分器失稳）**：`cellsim::step` 是显式欧拉

```
v' = v + dt·[ −(v−v_rest)/τ_m + Σ_c g_c·(E_c − v) ]
   = (1 − dt/τ_m − dt·Σg_c)·v + dt·(v_rest/τ_m + Σ g_c·E_c)
```

（E 只平移不动点，不参与稳定性。）稳定的充要条件是

```
|1 − dt/τ_m − dt·Σg_c| < 1     ⇔     Σ_c g_c < (2 − dt/τ_m)/dt
```

代入 dt=0.02、τ_m=0.1 ⇒ **Σg < 90**。实测 Σg≈1283（gc 1177 累加进去）时系数 = 1 − 0.2 − 25.7 = **−24.9**
⇒ 每步把 v 放大 25 倍并翻号 ⇒ 两三步就到 ±inf ⇒ 之后永久 NaN。

**修法**：在**总电导**上加这个稳定上限（并留 10% 余量 ⇒ 上限 81、系数 −0.82）：

```cpp
const float g_stable = 0.9f * (2.0f - B.dt / q.tau_m) / B.dt;   // ≈ 81
float gtot = Σ_c cc.g[c];
if (gtot > g_stable) for (c) cc.g[c] *= g_stable / gtot;        // 按比例缩，不改通道配比
```

**验证**：

| | 修前 | 修后 |
|---|---|---|
| sg=480 的 NaN 行数 | 23 | **0**（且 exit=0，表可读） |
| sg=16 / 60 / 128 / 1024 的 NaN | 有 | **0 / 0 / 0 / 0** |
| K=1 默认路径回归 SHA256 | — | **25F8563A…38B646（逐位不变）** |
| 守卫在 sg=16 的触发行 | — | **0**（主工作点完全不受影响） |

★ 三条踩过的半成品守卫（都记下来避免重犯）：
1. 上限取 **2e2 / 1e4** —— 都**高于**稳定边界 90，钳了也照样发散（NaN 只从 23 降到 16）。
2. 只钳**单通道** —— 稳定性约束的是**总和**；g=90 时系数恰好 −1.0（临界不衰减），仍有 16 行 NaN。
3. 更早一版按"单步 Δv ≤ 一个阈值裕度"钳 —— 钳到了正常细胞，默认路径当场变了
   （有发放神经元 71919→48553）。**已废弃。**

★ 副作用（必须说明）：守卫在 **sg≥60** 的格上会触发，所以 §3.2 工作点 B 的旧数字**已被取代**
（重跑：ol_intrinsic 294/238、visual 3/23、cb 67/79、desc 3/3、vnc 1/2；定性结论不变）。
主工作点 A（sg=16）不受影响、回归逐位不变。那些被钳住的工作点**本来就在稳定性之外**，
钳住只是把"算出 NaN"变成"算出饱和"。

（历史更正：第一轮报告里的「exit −1073741819 崩溃」是**我自己那段临时诊断代码的越界**
（`dbg_want[i]` 在空 vector 上下标），不是 NaN 的表现，已随诊断代码删除。）

## 8. K 非单调（参考 286→1821 单调，C++ cur K=4 11186 > K=8 7206）：一个假设 + 可证伪实验

**假设 H1（基线抬升 + 分支内稀释）**：两个效应随 K 反向变化 ——
1. **基线抬升**：`z = Σ_b g_b·relu(h_b − ϑ_b)`，对 `ϑ_b < 0` 的分支，即使 `h_b = 0` 也贡献
   `g_b·|ϑ_b| > 0`。ϑ ~ U(−0.1,0.1) ⇒ 期望有 K/2 个分支贡献 ≈ 0.05 的常数 ⇒ 基线驱动 ≈ 0.025·K。
   K 越大、整网被抬高越多（实测稳态 0.010→0.021 单调升），越多细胞被推近/进入 clamp，
   **动态范围被压缩** ⇒ 可检出的 on/off 差异变小。
2. **分支内稀释**：K 越大，每分支的入边越少 ⇒ 每个 `h_b` 越小 ⇒ 越容易落在 `ϑ_b` 以下被整流掉 ⇒
   有效非线性"变钝"。

**可证伪的最小实验（不必本轮做完）**：
- **实验 A（分离基线项）**：把分支阈值全部置零（`ϑ_b ≡ 0`，即 `--dend-theta 0` 或临时改
  `br_th` 的初始化）。H1 预测：基线项消失 ⇒ K=8 的 ol_intrinsic 显著数**回升到 ≥ K=4**，
  且单调性恢复。**若仍是非单调，H1 被否掉**（那就去看分支内稀释或别的机制）。
- **实验 B（等价工作点）**：保持 ϑ 不变，但把每个细胞的驱动减去其自身的 `Σ_b g_b·relu(−ϑ_b)`
  （即消掉那个常数项、只留"信号"部分）。H1 预测：两边的稳态活动被拉到同一档后，K=8 ≥ K=4。
- **实验 C（分支内容）**：比较 K=4 与 K=8 时"分支 0"（其余类别的桶）占的入边比例。
  H1 的机制 2 预测：K=4 时 top-3 类占比更大 ⇒ 分支更"纯"；若 K=8 的 top-7 之后仍有大量边落进分支 0，
  则分支 0 变成一个大杂烩、整流对它无效。这个只看数据、零成本（离线算即可）。

三条里**实验 C 最便宜**（纯离线、不跑网络），建议下一个先做它。
